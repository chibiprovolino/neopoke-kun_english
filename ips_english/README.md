# English patches, beta 1

Apply one patch to an unmodified dump of the game: 2 MB, CRC32 `6DF986A3`.
Any IPS tool works (Flips, Lunar IPS, or an online patcher).

| Patch | What you get | Patched CRC32 |
| --- | --- | --- |
| `neopoke_en_beta1.ips` | The English translation | `F9081C1D` |
| `neopoke_en_redesign_beta1.ips` | The translation plus the bonus patch: new events appear much faster, so minigames unlock sooner (see `docs/events-unlocks-redesign.md`) | `FC0B09BA` |
| `neopoke_en_allgames_beta1.ips` | The translation with a save that has all 30 minigames unlocked | `F88F684F` |
| `neopoke_en_redesign_allgames_beta1.ips` | The bonus-patch version with the same all-games save | `FD8C7DE8` |

The "allgames" save loads at boot. Once you save in the game, your own save is loaded instead.
