How the Script Desk works

One entry per unique line of the game's script. The left list groups them by scene; the filters at the top show what is left to do.

Editing

  • Type in Your English. The preview draws it in the font the game will use, and the counter shows the pixels left against that line's real width limit.
  • Codes like [1C] position the text: keep them. A new line in the box is a line break in the game.
  • Approve (Ctrl+Enter) marks the line done and moves on. Flag for later keeps it in the Flagged list; the note box is for remarks. Alt+↓/↑ move without saving a status.
  • V.OFF script lists the shooter's story in reading order, editable in place.
  • Too wide lists lines the build measured as wider than their window (written by tools/wide_flags.py).

Saving

    Export and Import

    • Export database downloads (or copies) a JSON file with every saved line and flag. Keep it as a backup, move your work to another browser, or put it into the build.
    • Import loads such a file. Lines in the file replace the same lines here; the others are kept.

    Into the build

    • python tools/merge_page.py script_desk_YYYY-MM-DD.json writes the saved lines into script/page.json.
    • python tools/build.py builds the ROM. python tools/check_fit.py build/tr_page.json build/fit.txt lists lines still too wide.
    • python tools/page_lines.py script/page.json review/lines.json refreshes the English this page shows for lines it never saved.
